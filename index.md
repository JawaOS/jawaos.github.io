# JawaOS

Hey, thanks for stopping by.

JawaOS is a small operating system we're building from scratch — no existing kernel underneath, no shortcuts, just us writing it line by line. It's still early days, so expect things to move around and break as we go.

If you'd like to follow along, come say hi in our [Discord](https://discord.gg/ad76sB6ked).
